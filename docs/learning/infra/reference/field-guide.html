Use the same words everywhere

Image / container
An image packages files and execution metadata; a container runs a process environment from that image. Our one app image serves two container roles.
Build / release / activation
A build produces artifacts. A release retains images, config and identity together. Activation changes which retained release runs on the host.
Tag / image ID
A tag is a movable name. Our images.env records exact local Docker image IDs; SHA256SUMS separately verifies archive and configuration bytes.
Compose service / project
A service is a declared role. A project groups services, networks and volumes. The host uses singular-seed so there is one web queue owner.
Published port / internal listener
Publication maps a host address and port into a container. Web listens on 8080 internally, but only Caddy has host port mappings.
Loopback
127.0.0.1 means the current network namespace. Web administration on its loopback is not the host’s loopback and not Caddy’s.
Unix socket
A local IPC endpoint accessed through a filesystem path. Shared socket mounts connect web and renderer even though renderer has no network.
Namespace / cgroup
A namespace separates what a process can see. A cgroup accounts for and limits a group of processes, including renderer children.
Liveness / readiness
Here, live checks that web is serving; ready requires a compatible renderer. Docker marks health status; unhealthy alone does not restart a container.
Admission / drain
Admission accepts work into a finite queue. Drain pauses new admission and waits for queued and running jobs; it does not preserve workspace memory.
Volume / backup
A named volume outlives ordinary container replacement. A recovery copy stored independently protects against loss of the host.
Terraform state / application state
Terraform maps configuration to cloud objects. Studio workspaces and jobs live in web memory; these are different things called state.
Rollback / restore
Rollback activates retained software/configuration. Restore recovers the state and access needed after loss. Neither recreates disposable process memory.
Vertical / horizontal scaling
Vertical adds capacity to one host; horizontal adds processes or hosts. Extra web instances need a shared admission and state design first.

When a source disagrees

Check the date and the implementation. The old systemd learning record is historical; the Compose decision supersedes it. For a configured value, follow the runtime file. For a claim that an operation succeeded, follow recorded evidence. For your understanding, explain it and let the agent challenge the explanation.
