# Learning records

Write a record when something non-obvious is now *known*, not when a tutorial
was merely read. Number them `0001-slug.md`. Keep them short: what changed in
your understanding, and what that does to the next stage.

Record 0001 preserves the historical systemd starting point. Record 0002
captures the owner's Compose decision; it does not claim target-host drills
have passed. Add measured observations and their practical consequences as
you complete the exercises.
