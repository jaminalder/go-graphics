# Curated publication beside the local laboratory

Keep one Go module with separate CLI and public application adapters. A public
catalogue explicitly admits artwork editions, visual choices, examples and
render budgets; registering an experimental sketch never publishes it.

This preserves unrestricted local artistic development while allowing a small,
coherent public experience. Share concrete recipe/configuration and exploration
mechanisms where the CLI and web are real consumers. Do not redesign artwork
internals into a universal scene/pipeline or expose CLI flags as web controls.
This preserves architecture decision 52 and extends decision 60.

See [the public architecture](../web/architecture.md) and
[implementation phases](../web/implementation-plan.md). This proposal does not
select the launch catalogue or assign licences.
