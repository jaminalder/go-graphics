# QQL

## Implemented algorithm

A complete dot/ring plan follows trait-selected flow fields and layout structures. A color plan selects background, related sequences, bounded swatch drift and substitutions. Planned marks are interpreted in ink or watercolour on a sequential canvas. Native QQL city swatches or a ColorLisa adaptation supply color.

## Controls and output space

Traits: flow-field, turbulence, margin, color-variety, color-mode, structure, bullseye, ring-thickness, ring-size, size-variety, qql-palette, spacing and medium. `--qql-palette colorlisa` adapts the global palette; other palette levels use native data.

## Rendering and review

Sequential paint path; ignores Context.AA/Deep. Use a 4:5 tall profile explicitly. Medium wash has more room with large rings and sparse spacing.

```sh
go run ./cmd/staticart render qql --seed 42 --profile preview-tall --out out
```
