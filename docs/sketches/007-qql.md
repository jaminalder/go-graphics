# Sketch 007 — `qql` (ring-dots packed along a flow field)

A port of Tyler Hobbs' and Dandelion Mané's **QQL**: ring-dots — concentric
circles drawn as a worked, hand-laid band rather than a printed one — strung
along the lines of a flow field and rejected wherever they would crowd a
neighbour. A single motif, an enormous range of outcomes.

Source for the port: the Rust reimplementation at
[`wchargin/qqlrs`](https://github.com/wchargin/qqlrs). Its weight tables,
spec formulas and layouts are copied faithfully; its entropy machinery is
not (see *Deviations*).

Native proportions are 4:5 — use `--profile preview-tall | web-tall |
print-tall`, or `make preview-qql`. It renders correctly at any aspect.

## Why this sketch exists, and what it brings the project

The other six sketches go *seed → RNG → draw*, with tunables bolted on as
CLI flags. QQL works differently, and the difference is the point.

A long-form algorithm is not a picture generator, it is a **designed output
space**. Hobbs' three essays (*The Rise of Long-Form Generative Art*, *The
Design Philosophy of the QQL Algorithm*, and his Right Click Save
interview) name what that demands:

- **Orthogonal features.** Twelve dimensions that are *independent* and
  *distinct* — each adds an axis rather than restricting the others. Twelve
  such axes is what makes the space large enough to be worth exploring.
- **Probabilistic, not binary.** "Large rings" resolves to a *distribution*
  of large sizes. Continuous, probabilistic features gave earlier work a
  "unified" feeling that camps of on/off switches did not, and they are what
  produce the one-in-a-million combinations.
- **A preserved motif.** Hobbs and Mané were "willing to sacrifice the range
  of some features in order to strongly preserve" the ring-dot. Minimum
  spacing is always kept and small dots shed rings rather than smudging, so
  the motif stays identifiable at every setting. That single constraint is
  what keeps the space coherent while everything else roams.
- **A quality floor with real outliers.** Bad outputs must be rare, not
  absent — with curation in the loop, an algorithm "can afford to take a lot
  of risk as long as 1% of them are excellent".

The trait machinery is therefore **not** in this package. It lives in
`internal/trait` so tapestry and the watercolour work can declare a schema
later and get the same seed-derivation, override and inspection plumbing.

## Pipeline

Each stage draws from its own RNG stream, so adding a consumer to one never
disturbs the values another sees.

| Stage | Stream | What it settles |
|---|---|---|
| Traits | `streamTraits` | the twelve discrete choices; CLI overrides applied on top |
| Specs | `streamSpecs` | flow-field shape, spacing, colour turnover, size ladder, ring counts, straight-line odds, stack offset |
| Field | `streamField` | the direction grid: linear or radial, plus turbulence eddies |
| Layout | `streamLayout` | start points, grouped — orbital, shadows or formation |
| Lines | `streamLines` | curve length; which groups ignore the field and run straight |
| Colour | `streamColor` | ground, the two winnowed sequences, splatter |
| Packing | `streamPack` | the dots themselves: size runs, colour walk, collision test |
| Painting | `streamPaint` | band jitter, stroke thickness, splatter placement |

**The packing loop is the piece.** The field says where dots would *like* to
go; the spacing rule decides which of those wishes survive. A dot is
accepted only if its spacing circle clears every circle already placed. That
one mechanism is why dense pieces come out as packed textures and sparse
ones as constellations — from identical flow lines.

Layout cost is resolution independent: preview and print of a seed place the
same dots, and both pay the same planning cost.

## Traits

QQL's twelve dimensions with its own rarity weights, plus one of ours.
Every one is a CLI flag; unpinned dimensions come from the seed.

| Flag | Values (weight) |
|---|---|
| `--flow-field` | horizontal 3 · diagonal 1 · vertical 3 · random-linear 1 · explosive 1 · **spiral 4** · circular 2 · random-radial 1 |
| `--turbulence` | none 2 · **low 3** · high 1 |
| `--margin` | none 1 · crisp 1 · **wide 2** |
| `--color-variety` | low 2 · **medium 4** · high 3 |
| `--color-mode` | simple 2 · **stacked 3** · zebra 1 |
| `--structure` | orbital 1 · formation 1 · shadows 1 |
| `--bullseye` | none · 1 · 3 · 7 · 1-3 · 1-7 · 3-7 · 1-3-7 (equal) |
| `--ring-thickness` | thin 1 · **thick 2** · **mixed 2** |
| `--ring-size` | **small 4** · medium 3 · large 1 |
| `--size-variety` | constant 1 · **variable 3** · wild 1 |
| `--qql-palette` | austin 1 · berlin 1 · **edinburgh 2** · **fidenza 2** · miami 1 · seattle 1 · **seoul 2** · colorlisa 0 |
| `--spacing` | **dense 2** · medium 1 · sparse 1 |
| `--medium` | **ink 1** · wash 0 |

Two values carry weight 0, so no seed ever lands on them and QQL's output
space is exactly the twelve dimensions above. `--qql-palette colorlisa`
hands colour duty to whatever `--palette` names, adapted into QQL's shape.
`--medium wash` paints the piece in watercolour — see below.

Inspect a seed without rendering:

```sh
staticart traits qql --seed 4711
staticart render qql --seed 4711 --structure shadows --ring-size large
```

The resolved palette always appears in the filename (`qql-p-edinburgh_…`),
pinned dimensions are added to it (`-str-shadows-rs-large`), and the full
trait set is embedded in the file's metadata alongside the render recipe.

## Structures

| `--structure` | Start points | Reads as |
|---|---|---|
| `orbital` | concentric bands around a centre, each cut into 1–3 arcs | record grooves; the centre is often off-canvas |
| `shadows` | 5–60 non-overlapping discs, each filled radially or as a raster | separate objects casting into a shared field |
| `formation` | a grid of rectangles, rastered, with some dropped | bands and blocks; the dropped chunks stop it reading as wallpaper |

A **group** — one arc, one disc, one chunk — is the unit that shares a
colour and a dot size, so the layout also decides how the piece divides into
passages.

## The ring-dot

A dot of radius `scale` is cut into `rings` bands. *Density* sets how much
of each band's share of the radius is ink: 0.93 is nearly solid, 0.17 a
target. Bands alternate the primary and secondary colours — visible only in
zebra mode, since otherwise both are the same colour.

Each band is laid down as **many thin concentric strokes**, every one nudged
off centre and re-thicknessed, with the first five rounds wandering further
than the rest. That is the whole texture: it frays the outer edge while the
interior stays solid, and it survives at every size.

`drawnRings` caps the count by radius — seven rings inside a three-pixel dot
would be a grey smudge, so small dots quietly shed rings until the motif is
visible again. **This cap is the load-bearing coherence rule of the whole
piece.**

### `--medium wash`

The same bands, laid as pools of watercolour (`paint.Wash.Ring`) instead of
as stacks of opaque strokes. Nothing about the piece moves: the layout, the
traits, the dots, their radii, thicknesses and colours are settled before
the medium is consulted and are identical either way, which
`TestMediumChangesOnlyThePaint` pins. Only the material changes — the band
gains a wet edge, a rim where the water dried, granulation and interior
pooling.

Two things the ink medium never has to think about:

- **Room.** A band under ~2px has nowhere to put a rim or a grain, so it is
  drawn as ink: identical pixels, a hundredth of the cost. A piece of very
  small dots therefore looks much the same in either medium. **The wash
  wants room** — pair it with `--ring-size large`, `--spacing sparse`, or
  both.
- **Body.** QQL paints opaque marks on a coloured ground, often a dark one.
  Transparent pigment cannot put light on dark at all, and laid thin every
  mark takes the ground's colour until the piece desaturates to the
  ground's hue. So each mark carries `Wash.Body`: a high baseline, raised
  further the more a mark is lighter than its ground. On a dark piece the
  marks come out as body colour — gouache — which is what a painter would
  reach for in the same situation.

```sh
staticart render qql --profile preview-tall --seed 5 \
  --medium wash --ring-size large --spacing sparse
```

## Colour

QQL's colour model is richer than a flat palette, so the primitive lives in
`internal/palette`: a `Swatch` is an HSB base plus, per channel, a standard
deviation and a clamp box it may never leave.

- A group's colour is **walked, not sampled**: `Swatch.Step` perturbs the
  *previous* value, so a run of dots is a family rather than a repeat.
- The sequence is **winnowed, not sampled**: colours are removed from the
  palette's long ordered sequence until the wanted count remains, so the
  survivors keep their neighbourly order and stepping along them still moves
  between related colours.
- The ground **rewrites the palette**: each background carries substitution
  rules that swap colours which would not read against it, or drop them.
- When the swatch changes mid-group the *current colour* is kept, so the
  walk crosses into the new colour instead of jumping to it.

## Per-seed draws

| Draw | Range | Purpose |
|---|---|---|
| dot radius | `w(0.0018)` – `w(0.3)` | the size ladder, per ring-size × size-variety |
| spacing radius | `max(scale·mult + const, scale·0.75)` | mult 0.98–1.75, const 0–`w(0.03)` |
| curve length | 500 · 650 · 850 steps | how far a flow line runs |
| field step | `w(0.002)` | line advance; samples at `h(0.002)` |
| turbulence | 0 / 10–30 / 20–60 eddies | θ spread `π·0.005` – `π·0.15` |
| margin | `w(-0.05)` / `w(0.003)` / `w(0.07)`, bottom `w(0.08)` | the bottom margin is the widest, as a mounted print wants |
| ring count | 1, 2, 3, 7 (or 2 when none selected) | capped by radius at paint time |
| density | 0.17 – 0.93 | ink versus gap within a band |
| colours in play | 1–5 / 5–15 / 10–25 | by colour-variety |
| splatter odds | 0 – 0.5 | 0.5 is a one-in-a-thousand piece that is almost all splatter |
| eccentricity | 0.007 of radius | keeps a field of circles from looking machined |

## Deviations from `qqlrs`

`qqlrs` is *entropy-exact* with the original QQL JavaScript: it reproduces
murmur2 seeding, a PCG variant carrying a JavaScript bit-drop anomaly,
table-based sin/cos, a Newton-iteration sqrt, a cached gaussian deviate, and
burns unused random draws to stay in step. All of that exists to make minted
seeds reproduce. None of it is ported.

| | `qqlrs` | here |
|---|---|---|
| Seed | 32 raw bytes | `uint64`, via `ctx.RNG(stream)` |
| Trait derivation | bit-masking the seed's last word; **weights ignored** | weighted draw per dimension |
| Coordinates | virtual 2000×2500 pixels | canvas units, height 1, width = aspect |
| Rasteriser | raqote; each stroke a tessellated polygon | analytic anti-aliased annulus (`paint.Ring`) |
| RNG | one stream, order-critical | one stream per stage |

Consequences worth knowing:

1. **Not bit-identical.** A given seed here is not a minted QQL piece. The
   vocabulary, distributions and character are.
2. **Weights actually apply.** `qqlrs`' `pluck` discards the declared weight
   and masks seed bits instead — an artifact of the on-chain mint, which
   makes flow fields uniform where the table says spirals should be common.
   Honouring the weights restores the quality-floor-plus-outliers shape the
   essays argue for. One table needed repair: `Turbulence::None` carries
   weight 0 yet the bit mechanism produced it about half the time; it is
   given weight 2 here (≈33%), damped so `low` stays the default character.
3. **The formation grid is repaired.** The source accumulates chunk origins
   in a float loop that rounding lets overshoot by one column or row lying
   wholly off-canvas — and because the first chunk after the shuffle is the
   one that can never be skipped, an overshot chunk landing there empties
   the piece outright. The source's own `with_capacity(across * down)` shows
   the intent; an integer loop is used instead.
4. **No polygon faceting.** `qqlrs` tessellates each stroke into as few as
   eight segments, so its smallest dots are visibly octagonal. Analytic
   annuli lose that. It is invisible below a few hundred pixels, and it is
   what makes 100k+ dots affordable at print size.

## Reuse, and what this sketch left behind

- `internal/trait` — **new**: weighted, orthogonal output-space dimensions,
  seed derivation, CLI overrides, filename and metadata plumbing. Built for
  this sketch, meant for the next one.
- `palette.Swatch` / `palette.HSB` — **new**: a colour with a clamp box and
  a random walk inside it. The watercolour work wants this.
- `paint.Canvas.Ring` — **new**: analytic anti-aliased elliptical annulus.
- `geom.NewIndexIn` — **extended**: explicit bounds (packing runs 5% past
  the canvas) and an explicit cell size (QQL's radii span two orders of
  magnitude, so sizing cells by the largest would go quadratic).
- `sketch.Traited` — **new** optional interface, so `cmd` can report and
  record traits without knowing anything about QQL.

The sampling vocabulary the trait tables are written in — weighted choice,
gaussians, `winnow` — is still local to this package (`sample.go`). Promote
it to a shared leaf when a second sketch needs it, not before.

## Acceptance checklist

- [ ] The ring-dot is identifiable at every size — small dots shed rings
      rather than becoming grey smudges.
- [ ] Band edges read as worked, not printed: visible offset strokes at
      print size, clean silhouettes at preview size.
- [ ] Each structure is distinguishable at a glance: orbital sweeps,
      shadows clusters, formation bands.
- [ ] Colours drift within a passage and turn over between passages; no
      confetti unless colour-variety is high.
- [ ] Margins are respected, and the bottom margin reads as the widest.
- [ ] Sweeping ~20 unpinned seeds gives real variety with few duds; a piece
      is never empty.
- [ ] `--qql-palette colorlisa --palette <slug>` reads as a coherent piece.
- [ ] Preview and print of the same seed show the same composition.
- [ ] `--medium wash` gives the same composition as ink, in paint: worked
      wet edges, a visible rim, and pigment that still reads as the colour
      the traits chose rather than as the ground's hue.
