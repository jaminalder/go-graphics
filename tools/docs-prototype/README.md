# Documentation browser edition

This directory retains the formatting prototype's path and implements the complete project documentation site. All Markdown under `docs/` is built, including disconnected pages. The three reading layouts, responsive tables, Mermaid diagrams, source links and print styles apply to every page.

See [documentation maintenance](../../docs/development/documentation.md) for commands, prerequisites, offline caching and checks. Generated files belong in `out/docs/`, never in `docs/`.
